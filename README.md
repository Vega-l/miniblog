# Miniblog

一个把账号、动态和评论都存在浏览器里的小型发布页。纯 HTML + CSS + JavaScript，无框架、无构建、无后端。

## 功能

- **账号**：注册、登录、退出，用户名唯一，密码加盐哈希后保存
- **发布**：登录后可发布，单条上限 280 字，空内容不可提交
- **时间线**：按发布时间倒序展示，最新在最上面
- **评论**：每条动态可展开评论，评论上限 140 字，实时更新评论数
- **个人主页**：查看自己发过的帖子和发表过的评论，评论可一键定位回原帖
- **游客浏览**：未登录可以看时间线和评论，点发布或评论时引导登录
- **持久化**：全部数据写入 LocalStorage，刷新、重开浏览器后仍在
- **热搜侧栏**：右侧展示全网热搜 TOP 10，可手动刷新，请求失败自动回退缓存或内置数据
- **布局**：双栏（主内容 + 侧栏），1040px 以下侧栏自动沉到内容下方
- **视觉**：新粗野主义 —— 米黄纸感底、3px 黑描边、无模糊硬阴影、黄粉蓝撞色

不含点赞、删除、编辑资料、多设备同步。

## 目录

```text
miniblog/
├── index.html    # 页面结构、弹窗、模板
├── styles.css    # 全部样式（玻璃拟态主题、背景光晕、动效降级）
├── js/
│   ├── store.js     # 存储层：读写、数据清洗、旧数据迁移
│   ├── auth.js      # 账号：注册、登录、会话、密码哈希
│   ├── trending.js  # 热搜：拉取、缓存、降级、渲染
│   └── app.js       # 界面：渲染、事件、视图切换
├── data/
│   └── trending.json  # 热搜数据源，可替换为自己的接口
├── README.md
├── .gitignore
└── .nojekyll     # GitHub Pages 跳过 Jekyll 处理
```

四个脚本按顺序以普通 `<script>` 引入，不使用 ES Module。`file://` 直接双击也能打开，但浏览器会拦截 JSON 请求，此时热搜改用脚本内置的兜底数据；想读到 `data/trending.json`，请用本地静态服务打开。

## 本地运行

直接双击 `index.html` 即可，无需服务器。也可以起一个本地静态服务：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 数据结构

| LocalStorage 键 | 内容 |
| --- | --- |
| `miniblog.users.v2` | 账号数组：`id`、`username`、`displayName`、`salt`、`passwordHash`、`createdAt` |
| `miniblog.posts.v2` | 动态数组：`id`、`authorId`、`content`、`createdAt` |
| `miniblog.comments.v2` | 评论数组：`id`、`postId`、`authorId`、`content`、`createdAt` |
| `miniblog.session.v2` | 当前会话：`{ userId }` |

所有读取都会经过清洗：丢弃非法项、补默认值、截断超长文本。`authorId` 为 `null` 表示旧版本遗留的无主内容，展示为「之前的访客」。

### 从 v1 升级

旧版本的 `miniblog.posts.v1` 只有内容和时间。首次打开新版本时自动迁移为 v2，作者标记为无主；**第一个注册的账号会接管全部无主内容**，之后 v1 键被删除。

### 热搜数据

侧栏读取同源的 `data/trending.json`，格式：

```json
{
  "updatedAt": "2026-11-13 09:40",
  "source": "演示数据（可替换为真实接口）",
  "items": [{ "title": "标题", "hot": "982.4万", "tag": "科技" }]
}
```

- 只取前 10 条，`hot`、`tag` 可以省略
- 请求成功后写入本地缓存，5 分钟内复用；失败时先回退缓存（标注「缓存」），再回退脚本内置数据（标注「内置演示数据」）
- 换成自己的接口：修改 `js/trending.js` 顶部的 `ENDPOINT`，接口需允许跨域（CORS）
- 仓库里这份 JSON 是演示内容，不是实时热搜

## 账号的安全边界

这是纯前端演示，请按以下前提使用：

- 账号、会话、内容全部存在本机浏览器，换设备、换浏览器、清除站点数据都会丢失
- 密码用随机盐 + SHA-256（`crypto.subtle`）计算后存储，环境不支持时降级为内置弱哈希；但页面本身没有任何服务端校验，任何人都能通过开发者工具改写本地数据
- 没有找回密码、没有邮箱验证、没有频率限制
- 不要在这里使用任何真实密码

## 实现要点

- 内容一律用 `textContent` 写入，配合 `white-space: pre-wrap` 保留换行，天然规避 HTML 注入
- 发布与评论都是「先写存储、成功后再更新界面」，失败时回滚并提示，避免出现界面有、刷新就没
- 评论按 `postId` 关联，加载时清理孤儿评论；删除逻辑未实现，因此不存在悬空引用
- 展开评论用 `Set` 记录状态，登录态变化导致重绘后仍能保持展开
- 个人主页的「查看原帖」会切回时间线、展开该帖评论并高亮定位
- 热搜请求带 6 秒超时与 `AbortController`，任何环节失败都不会让侧栏空白
